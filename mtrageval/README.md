# MTRAGEval

MTRAGEval is a task for Evaluating Multi-Turn RAG Conversations at [SemEval 2026](https://semeval.github.io/SemEval2026/). For full details see the [MTRAGEval website](https://ibm.github.io/mt-rag-benchmark/MTRAGEval/).

MTRAG-UN is the evaluation benchmark for MTRAGEval. Sample data is available in [sample_data/](sample_data/).
